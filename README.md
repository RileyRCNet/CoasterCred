#First public beta of CoasterCreds – track every roller coaster you've ridden.

How to install (Android 8+):
1. Download CoasterCreds-0.2.0-beta.apk below.
2. Open it; if asked, allow installing from your browser/files app.
3. Make an account in Profile → Settings to back up your credits and add friends.

Coaster data from Wikipedia/Wikidata, photos from Wikimedia Commons, live queue times from Queue-Times.com.
